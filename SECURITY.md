# Security Policy

## Supported versions

Only the latest version deployed from the `main` branch is supported.

## Reporting a vulnerability

Please do **not** open a public issue for security problems.

Report privately through GitHub:
[Report a vulnerability](https://github.com/MacroMaster101/Vero_Salon_Website/security/advisories/new)

Include what you found, the steps to reproduce it, and the impact you expect.
You should get a reply within a few days. Please give us a reasonable amount
of time to fix the issue before disclosing it publicly.
